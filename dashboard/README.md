# Dashboard

Unified web/mobile UI for the Home Control System.

## Features (Planned)

- Real-time status display of all connected systems
- Control panels for lighting, HVAC, security, and media
- Notification center for alerts and events
- User management interface
- Responsive design (desktop, tablet, mobile)

## Communication

- Connects to Gateway via HTTPS/WebSocket
- Subscribes to MQTT topics via WebSocket bridge for real-time updates
